# Partnerships

`Partnerships` 用来说明 VIRTURA 作为一个创意网络，如何与学校、机构、企业、协会、驻地平台和其他组织形成合作关系。

它既服务 `inbound` 邀请，也服务 `outbound` 合作申请与关系建立。

## 我们带来的不只是单个讲者

VIRTURA 的价值不只是“找一个人来做一件事”，而是可以把以下几种能力接起来：

- 研究、写作与公共表达
- 视觉系统、数字空间与作品前台
- 交互、装置、空间执行与现场落地
- 项目经验、工具原型、知识网络与长期归档

所以我们更适合进入那些既需要内容，也需要结构判断的合作。

## 我们最适合形成关系的对象

### Schools / Education

适合 guest lecture、workshop、summer school、studio module、联合课程与教研合作。

当前可重点展开的方向是 `VR / XR Practice Training`：把虚拟现实技术实习实训、Unity / OpenXR、讲师 Inspector、Viewer Tracker、AI 辅助开发和项目归档做成可复用教研资产。

### Institutions / Residencies / Public Programs

适合研究合作、公开项目、驻地、展览前期讨论、项目孵化与公共活动。

### Companies / Brands / Innovation Teams

适合空间内容、数字展演、展示结构、内容咨询、实验型 public-facing 系统与合作研究。

### Spatial Design / Production Systems

适合和空间设计事务所、展陈执行团队、新媒体制作系统形成分工协作。

### Associations / Networks

适合协会项目、行业活动、联合论坛、实践展示与跨团队协作网络。

## Inbound Routes

如果你是来邀请我们的：

- 想做讲座、workshop 或线上分享：看 [Programs](../programs/README.md)
- 想做课程、summer school 或 studio module：看 [Education](../programs/education/README.md)
- 想围绕具体项目做结构诊断、视觉前台、互动层或项目表达咨询：看 [Consulting](../programs/consulting/README.md)

## Outbound Routes

如果我们主动向你们递交申请、提案或合作意向，当前最自然的方向包括：

- summer school / visiting faculty / school module
- residency / lab / research-based public program
- exhibition / cultural program / spatial content collaboration
- enterprise innovation / branded spatial experience / experimental content system
- association / network / forum / industry-linked cultural project

我们更适合那些允许“研究 + 作品 + 系统 + 实作”一起进入的合作，而不只是单一外包关系。

## Network Context

在当前可公开的语境里，VIRTURA 不是一座孤岛，而是处在一个更大的协作网络中：

- `VIRTURA`：跨学科艺术团队与创意网络，负责作品、系统、研究与公共入口
- `SpacePort`：项目、活动与公共程序的承载平台
- `XUAN (轩空间感知)`：由沈轩主理的空间设计与项目实践框架
- `TZONE (上海图域)`：`XUAN` 体系下的新媒体空间设计品牌，同时是上海市多媒体行业协会副会长单位

这意味着 VIRTURA 既能保持艺术团队的自主性，也能在合适项目里与成熟空间设计、制作执行与行业网络形成连接。

## 我们更喜欢怎样开始

最好的开始不是空泛寒暄，而是带着一个明确判断：

- 你们要解决什么问题
- 更需要课程、项目、研究还是系统合作
- 时间窗口和大致预算怎样
- 需要单人、双人、团队还是跨网络协作

对于学校实训、文旅空间、展陈交互或 Apple Vision Pro demo 这类合作，VIRTURA 会优先确认交付层级、验收证据、付款节点和需求变更边界。这样合作不会被模糊排期、反复追加需求或低估技术准备成本拖散。
