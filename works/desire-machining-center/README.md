## Current Summary

`Desire Machining Center / 欲望加工中心` 可被理解为一件围绕欲望、选择、反馈和价值构造展开的交互装置作品。

它与 VIRTURA 的关系主要在于：

- 把低欲望文化、虚拟补偿和选择机制转化为可操作的装置结构
- 连接交互艺术、空间执行和观众反馈
- 与 VIRTURA 的作品网络、Programs 和公共评论语境形成交叉
