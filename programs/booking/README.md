# Booking

如果你想从 `Programs` 进入，建议先说明 5 件事：

1. 这次面向谁
2. 你更需要 `talk`、`workshop`、`consulting` 还是 `virtual talk`
3. 希望的时长和时间窗口
4. 最终希望得到什么
5. 有没有已经存在的项目、课程或空间背景

## 如果你还不确定该约谁

- 想聊数字空间、视觉系统、公开前台：优先看 [Ewan Qian](../../artists/ewan-qian.md)
- 想聊写作、研究、跨媒体叙事、research sharing：优先看 [Murphy Nile](../../artists/murphy-nile.md)
- 想聊交互艺术、装置协作、空间执行、现场互动层：优先看 [Sihui Xu](../../artists/sihui-xu.md)
- 想围绕一个完整主题做团队分享：直接按 collective 组合来说明需求

## 快速路由

- 更像公开讲座或专题分享：先看 [Talks](../talks/README.md)
- 更像实操型课程或工作坊：先看 [Workshops](../workshops/README.md)
- 更像围绕具体项目做诊断：先看 [Consulting](../consulting/README.md)
- 更像先远程认识或做线上分享：先看 [Virtual Talks](../virtual-talks/README.md)

## 当前原则

- 先判断主题是否适合 collective 进入
- 再判断更适合单人、双人还是团队组合
- 再进入排期、执行和更细的合作边界
