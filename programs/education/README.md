# Education

`Education` 面向学校、summer school、studio module、驻地教学与研究型课程合作。

它不是普通讲座目录，而是 VIRTURA 作为一个创意网络如何进入教学、研究与长期合作系统的公开入口。

## 我们为什么适合学校合作

VIRTURA 的优势不只在单个讲者，而在三种能力可以互补进入：

- Murphy：研究、写作、案例框架、国际语境与 public program 转译
- Ewan：数字空间、视觉系统、作品前台、场景叙事与结构组织
- Sihui：交互、装置、执行、协作链路与从原型到现场的落地经验

这意味着我们既能讲概念，也能讲项目，还能讲怎么真正做出来。

## 适合的学校合作类型

- guest lecture / visiting talk
- workshop / practice-based seminar
- duo or trio intensive session
- summer school / bootcamp
- studio week / short residency module
- 长周期研究合作或联合教研方向

## 当前重点模块：VR / XR Practice Training

现在可以把 `VR / XR Practice Training` 作为一个更明确的学校合作入口来谈。

它适合虚拟现实技术、数字媒体、交互设计和新媒体艺术相关专业，把 `认识实习 5 天`、`专业实习 10 天双轨`、`讲师 Inspector`、`Viewer Tracker` 和 `统一工程模板` 接成可报批、可执行、可归档的教学工程包。

详细入口：[VR / XR Practice Training Module](./vr-xr-practice-training.md)

## 适合的机构类型

- 新媒体艺术、数字媒体、实验影像、交互设计相关专业
- 想补空间内容、XR、实时系统或数字展演方向的学校
- 研究型社群、艺术机构、公共项目、驻地和实验平台
- 希望把“作品 + 方法 + 实作”打通的教学场景

## 推荐合作梯度

### 1. Guest Talk

先用一场公开分享或课程客座判断是否匹配。

### 2. Practice Workshop

从单次 talk 进入到实操、案例拆解或项目练习。

### 3. Duo / Trio Intensive

围绕研究、视觉、交互三条线做半天到一天的集中模块。

### 4. Summer School / Studio Week

适合学校假期课程、短期驻留、联合工作坊与阶段性成果展示。

### 5. Long-term Lab Collaboration

如果合作持续成立，可以进一步发展成联合研究、长期模块、线上 campus 或 skills-based 教学系统。

## 我们最理想的长期状态

不是只做零散讲座，而是逐步从：

`guest lecture`
→ `module`
→ `summer school`
→ `studio week / residency`
→ `长期教研合作`
→ `虚拟 campus / skills-based 教学系统`

这一条线慢慢长出来。
