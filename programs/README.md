# Programs

`Programs` 是 VIRTURA Collective 当前面向外部的邀请入口。

这里不替代作品页，也不替代协作页，而是专门回答一件事：

外部如果想邀请我们做分享、工作坊、咨询、线上交流或学校合作，可以从哪里开始进入。

## Programs 是什么

- 它是 `invite us` 的公开入口
- 它适合学校、机构、企业、展览项目和公共活动先判断怎么进入
- 它不是内部报价单，也不是我们对外投递申请的完整档案

## How We Work Together

如果按 collective 进入，而不是单人邀请，现在最自然的组合是：

- Murphy：语言、研究和公开表达框架
- Ewan：视觉、场景和数字空间结构
- Sihui：交互、装置和现场落地

这更适合做一整套团队分享、工作坊、咨询合作或学校模块，而不是三个人各自平行发言。

## Sample Collective Formats

### Single Speaker

适合专题分享、课程客座、线上对谈或小型 workshop。

### Duo Session

适合研究 + 视觉、视觉 + 交互这类双线组合。

### Trio Session

适合从研究框架、视觉系统到交互落地的完整 collective session。

### VR / XR Practice Training

适合学校实习实训、短期工作坊和联合教研模块。它把课程报批、Unity / OpenXR 实操、讲师 Inspector、Viewer Tracker、AI 辅助开发和项目归档接成一套可执行教学工程包。

入口：[Education / VR-XR Practice Training](./education/vr-xr-practice-training.md)
