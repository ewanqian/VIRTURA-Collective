# Consulting

`Consulting` 不是大而全顾问口径，而是围绕 VIRTURA 当前已经公开成立的能力边界展开。

## 推荐时长

- 30 分钟：问题校准或 scoping call
- 60 分钟：单次诊断与建议
- 90 分钟：工作会，适合带着具体页面、项目或空间进来

## 当前模块

### [Ewan Qian](../../artists/ewan-qian.md)

- 主题重点：数字空间、视觉系统、公开前台与信息结构
- 30 分钟：判断项目前台、视觉系统或数字空间表达的主要卡点
- 60 分钟：对公开前台、项目结构或视觉路径做一次集中诊断
- 90 分钟：围绕现有项目做信息结构与视觉前台 working session

### [Sihui Xu](../../artists/sihui-xu.md)

- 主题重点：交互层、装置层、空间执行与现场配合
- 30 分钟：快速判断现场版本或互动层的关键问题
- 60 分钟：围绕装置协作、互动路径或执行流程做一次诊断
- 90 分钟：带着具体空间或项目做落地链路梳理

### Murphy Nile 的更适合形式

- 写作、研究与公开表达框架更适合走 [Talks](../talks/README.md) 或 [Virtual Talks](../virtual-talks/README.md) 的 seminar / critique 形式
- 如果需求更接近研究转 public program，也可以在 [Booking](../booking/README.md) 中说明具体场景

## 更适合的合作对象

- 需要把项目整理成可公开前台的团队
- 正在做展览、展演或空间项目的协作者
- 想把研究、写作、案例与项目说法收束起来的内容团队
