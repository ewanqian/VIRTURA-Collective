# Virtual Talks

`Virtual Talks` 适合线上分享、远程 studio visit、research sharing 或 critique。

## 推荐时长

- 30 分钟：线上短讲或 guest session
- 60 分钟：标准 remote sharing
- 90 分钟：分享加讨论，适合 critique 或 review

## 当前模块

### [Murphy Nile](../../artists/murphy-nile.md)

- 主题重点：写作、研究、数字空间观察、跨媒体叙事
- 30 分钟：围绕一个观察主题做线上短讲
- 60 分钟：研究与案例分享，适合学校或研究社群
- 90 分钟：研究转 public program、跨媒体叙事或 critique，适合对谈

## Collective Remote Session

- 60 分钟：Murphy 主讲，按主题邀请 Ewan 或 Sihui 补一个项目案例段
- 90 分钟：线上主题分享加 open critique，更适合国际交流或研究活动

## 当前适合的主题

## 适合对象

- 国际交流场景
