# Workshops

`Workshops` 更适合那些希望从“听分享”进入“实际试做”的场景。

## 推荐时长

- 30 分钟：导入型 demo 或 preview，不是完整 workshop
- 60 分钟：单主题 working session
- 90 分钟：标准 workshop，包含练习与反馈
- 半天：围绕一个真实项目做定制 workshop

## 当前模块

### [Ewan Qian](../../artists/ewan-qian.md)

- 主题重点：场景构成、视觉系统、数字前台整理
- 30 分钟：快速拆一个空间或视觉案例
- 60 分钟：把一个项目整理成可读的视觉系统
- 90 分钟：围绕参与者项目做场景构成与公开前台重组
- 半天：围绕展览、课程或数字展演项目做定制 workshop

### [Sihui Xu](../../artists/sihui-xu.md)

- 主题重点：交互艺术、装置协作、空间执行、现场互动层
- 30 分钟：快速梳理一个互动或装置案例的协作层
- 60 分钟：拆解现场版本中的互动与空间执行逻辑
- 90 分钟：围绕一个具体项目做原型到落地的协作演练
- 半天：适合展陈项目、实践课或品牌空间团队的共创工作坊

### Murphy Nile 的更适合形式
